# OGFINDERMACOS

Pair Arama - macOS sürümü. Pump.fun ve Stonk.fun token arama arayüzü.

## Kurulum
1. [Node.js LTS](https://nodejs.org) ve Google Chrome kurun.
2. Depoyu ZIP olarak indirip çıkarın.
3. `Pair Arama.command` dosyasını açın. Gerekirse Terminal'de `bash "Pair Arama.command"` çalıştırın.
4. Alternatif: `node server.js` ardından `http://127.0.0.1:4317`.
5. Benzer fotoğraf analizi için `npm install` çalıştırın.

Sunucu yalnızca yerel bilgisayarda dinler. Hatalar için `pair-arama.log` dosyasını inceleyin.
